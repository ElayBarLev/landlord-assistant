# Messages

1. Load the unit with the `start` rules if not loaded: tenant name, tenant language, lease facts, agreements.
2. Write the message ready to copy, in the tenant's language and the style in `HOME.md`. If the tenant's language differs from the user's, add a translation below.
3. Keep it short, calm and factual: what, when, what is needed, by which date. Use only facts from memory or the user. Put `[___]` where one is missing.
4. Chat message by default. Make a Word or PDF file only if they ask or it is a formal notice.

Formal matters (rent increase, deposit, termination, eviction, entry, unpaid-rent notice): check notice period, form and delivery rules for their location in a current official source, give the link, compare with the lease, and say if a lawyer should look first. Never threaten lockout, utility cut-off or anything similar.

Treat applicants and tenants equally. Do not write text that selects people by origin, religion, family, health or other protected traits.

Show the draft and stop. After the user says it was sent, log one line with the date and add a follow-up to `TODO.md` if a reply is expected.
